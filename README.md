# Simple Symbol Support

A free browser tool for classrooms, from **Communicate by Design**.

Two things in one page, no install and no account:

- **Print symbol cards** — type words, get a printable sheet of picture cards at a
  true measured size, with space between them for cutting.
- **First–Then board** — First/Then, Now/Next, or your own labels. Print it for
  laminate and velcro, or open it on a device where tapping a box says it aloud.
  Optionally let the student choose what comes next.

Multi-word phrases work: "back stretch" finds *stretch*, and the card keeps the
label you typed. Card borders are colored by word type using the Fitzgerald Key.

**One thing that matters when you print:** set Scale to **100%**, not "Fit to page."

## On an iPad

Open the page, add it to your Home Screen, then turn on Guided Access. That gives a
full-screen app locked to the board.

## Privacy

Nothing is uploaded and there is no account. The only thing that leaves the page is
the vocabulary word itself, used to look up a picture for it. If you use the choice
log, it stays in that browser on that device and is written to a file only when you
click Export.
